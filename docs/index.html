从零到独立设计 Agent Skills

一套面向零基础学习者的中文课程：从理解 AI Agent、读懂 Agent Skills 规范，到写出能被可靠触发、可评估、可维护的高质量 Skill。

阶段：全课程 · 建议 12 分钟

这门课假设你此前没有 AI 工程经验。它从一个问题开始：怎样把“你脑子里会做某件事”变成“Agent 每次都能按你的方法做好这件事”？答案就是 Agent Skill（技能）。

这门课解决什么问题

大语言模型（Large Language Model，LLM）很会写通用文本，但它不知道你们团队的评审规则、你们的数据库字段命名、你们那份 PDF 表单里哪个字段必须留空。你可以在聊天里解释一遍，但下一次会话它又忘了；你也可以把说明写进一个随手保存的文档，但 Agent 不会主动去读。

Agent Skills 做的事很朴素：把“完成某类任务所需的专门知识和工作流程”放进一个目录，用一份约定格式的 SKILL.md 描述它是什么、什么时候该用，让支持该格式的 Agent 在需要时自己加载。[源站]

难的不是格式。格式只有六个字段，半小时能背下来。难的是判断：哪些内容值得写、写到什么程度、怎样让它在正确的时刻被触发、怎样证明它真的比没有它更好。这门课的大部分篇幅都在训练这种判断力。

一句话课程目标

读完并完成练习后，你能独立完成一次端到端交付：从一个真实任务出发，写出结构正确、触发可靠、经过评估、可被他人维护的 Skill，并能说清每个设计取舍的理由。

五阶段学习路径

课程按“先建立心智模型，再读规范，再练设计，再校准触发与质量，最后交付”的顺序组织。每个阶段都有明确的进入状态、离开状态和时间预算。完整说明见学习路径。

S1

认知准备

理解 Agent、工具调用、上下文窗口与渐进披露。约 2 小时。

从“什么是 Agent”开始

S2

读懂规范

目录结构、六个 frontmatter 字段、三级加载、生命周期与校验。约 2.5 小时。

打开规范部分

S3

写出好内容

从真实专长出发，做上下文减法，校准控制强度，套用六种指令模式。约 5 小时（含教程）。

学习设计方法

S4

触发与评估

把描述写成触发入口，用查询集测触发率，用断言和基线测输出质量。约 2.5 小时。

学习触发与评估

S5

交付与迁移

读三个跨领域案例，完成毕业项目，用评分表和反模式清单自检。约 6 小时。

进入实战案例

学完后你能做到

  • 看懂任何一个符合规范的 Skill，并判断它的范围、结构和触发描述是否合理。
  • 把一个你熟悉的重复性任务拆成“必须写进 Skill 的专门知识”和“Agent 本来就会的通用能力”。
  • 写出 frontmatter 合法、正文精炼、支持文件按需加载的 Skill，并通过 skills-ref validate 校验。
  • 用 20 条左右的真实查询评估触发准确率，用训练/验证划分避免过拟合。
  • 用评估用例、断言和“有 Skill / 无 Skill”对照，给出可复核的质量证据。
  • 向同事解释为什么某个 Skill 这样设计，并依据评分表评审他人的 Skill。

如何使用本站

  • 按顺序读：每页末尾的“上一页 / 下一页”构成一条完整阅读线，与学习路径一致。
  • 用目录跳转：桌面端左侧是本页目录，窄屏时目录移到正文上方。
  • 搜索：页头搜索框支持标题、模块和关键词，按 / 可快速聚焦；搜索完全在本地运行，离线可用。
  • 动手：教程与案例中的文件都可以直接复制。所有完整示例 Skill 也放在仓库的 examples/ 目录，便于对照。
  • 自检：每个模块末尾都有基础 / 进阶 / 挑战三级练习，参考答案要点折叠在题目下方。最后的检查清单可打印。

关于来源与诚实标注

课程以 agentskills.io 的九页公开文档为主要依据，检索日期为 2026-11-25。为了让你能核对每一处说法，正文使用四种固定标注：

  • [源站] 表示可在 agentskills.io 的非规范页面找到依据，来源页列出了具体 URL。
  • [规范] 表示来自 specification.md 的规范性内容或硬性约束。
  • [外部: https://…] 表示来源之外的权威资料，必须附可访问 URL。
  • [本课程观点] 表示本课程的类比、练习、时间估计、评分表等教学设计，不代表官方规范。

我们不伪造引文、章节名或规范细节。来源页面没有写的内容，会明确标为 [本课程观点] 或 [外部: URL]。少数页面（例如客户端展示页）内容由网页动态生成、无法静态取回，这一点在来源页中如实说明。

从这里开始

如果你只有 15 分钟，先读学习路径，再决定投入多少时间。如果你想马上做出第一个 Skill，可以直接跳到教程 1，遇到不懂的概念再回来补预备知识。

标准路线建议按顺序完成 S1 到 S5。每完成一个阶段，用毕业自检门禁中对应的问题问自己一遍；如果答不上来，回到该阶段的对应页面，而不是继续往下读。
