检索方法与日期

全部来源页面的检索日期为 2026-11-25。站点索引来自 https://agentskills.io/llms.txt（同日检索）。检索方式是直接请求各页面的 Markdown 版本（.md 地址），读取完整正文。九个页面均成功返回 HTTP 内容；其中 clients.md 的客户端列表由网页动态渲染，静态取回时只得到标题与排序控件，因此本课程没有据此列出具体客户端，也不声称覆盖其完整名单。

规范与事实以检索当日的内容为准。Agent Skills 是开放标准，页面可能更新；如果你的版本与课程不一致，以官方页面为准，并欢迎把差异视为学习材料。

哪些不是来源内容

以下内容由本课程原创，不代表 agentskills.io 或任何客户端的官方立场：

  • 全部中文表述与翻译；来源为英文。
  • 五阶段学习路径、时间估计、先修要求与毕业门禁。
  • “交接文档”“图书馆目录”“外行会做错”等类比与教学方法。
  • 所有练习、提示、参考答案要点与自检标准。
  • 三个实战案例的情境、需求、被否决方案与验证设计。
  • 毕业项目的权重分配、1/3/5 分描述与反模式清单。
  • 示例技能中的具体业务流程、脚本与虚构数据（如 example-org、样例 CSV）。
  • 本站的视觉设计、导航、搜索与链接检查工具。

背景页中的 LLM、上下文窗口等基础定义，部分采用本课程的简化表述，已用 [本课程观点] 标注；外部可核实的事实另以 [本课程观点] 标注并给出链接。

引用与措辞

课程对来源内容以转述为主，少量短句引用用于说明关键定义（例如“补上 Agent 缺的，省掉它已经知道的”）。没有大段复制来源原文，也没有虚构引文、章节名或规范字段。若你发现某处表述与官方页面不一致，请以官方页面为准。

来源中的表格、字段名、限制值（64 字符、1024 字符、500 字符、500 行、5000 token、约 100 token、50–100 token）均按检索当日内容转述。规范把这些称为“建议”的地方，课程也保留“建议”的限定，没有写成硬性校验。

归属与许可

Agent Skills 格式最初由 Anthropic 开发，作为开放标准发布，并由越来越多的 Agent 产品采用。[源站] 官方仓库与讨论入口：github.com/agentskills/agentskills。参考校验库位于该仓库的 skills-ref 目录。

本课程是独立的学习材料，与 agentskills.io、Anthropic 或任何客户端厂商无隶属关系，也未获得其背书。课程文本与示例代码可自由用于学习与内部培训；转载或再发布时请注明来源链接与本课程名称。来源页面本身的版权归其各自作者所有。

完整性说明

  • 九个来源页面均已尝试并成功取回正文；无因失败而编造内容的页面。
  • clients.md 的动态列表无法静态取回，已在正文与上表中明确说明，未虚构客户端名称。
  • 来源未提供的内容（例如具体时间估计、评分权重、练习答案）均标为 [本课程观点]。
