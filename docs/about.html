关于本课程

课程目标、目标读者、教学设计、技术实现、已知限制与使用许可。

阶段：参考 · 建议 8 分钟

这是一套独立编写的中文课程，目标是把“会写 SKILL.md”提升为“能判断什么样的 Skill 值得写、能被可靠触发、能被验证和维护”。

课程目标

  • 让没有 AI 工程背景的读者理解 Agent、工具调用、上下文与渐进披露。
  • 准确讲清 Agent Skills 的格式规范，不把“建议”写成“硬性要求”，不把客户端行为写成规范。
  • 训练可迁移的设计判断：范围、上下文经济、控制校准、触发、验证。
  • 通过四个教程与三个案例，让读者完成从模仿到独立交付的过渡。
  • 提供一个可打印的检查清单与 100 分评分表，使自我评估和同行评审有共同标准。

适合谁

适合

  • 第一次接触 Agent Skills，希望系统入门的产品、运营、设计、工程人员。
  • 已经能写提示词，但想把重复流程固化成可维护资产的人。
  • 需要在团队内推广技能库、制定评审标准的负责人。

不完全适合

  • 想直接学习某个客户端内部实现细节的读者；课程只讲到生命周期与加载机制。
  • 寻找现成技能市场或安装包的读者；课程不提供技能分发服务。
  • 希望零阅读、只看代码的读者；设计判断需要文字说明。

教学设计

  1. 五阶段路径。 认知准备 → 读懂规范 → 写出好内容 → 触发与评估 → 交付与迁移。每阶段有进入/离开状态、先修、时间、页面与可观察能力。
  2. 四种来源标注。 [源站]、[规范]、[外部: URL]、[本课程观点]。读者可以随时区分来源事实、规范、外部背景与教学框架。
  3. 每模块三级练习。 基础 / 进阶 / 挑战，均附提示或参考答案要点，便于自检。
  4. 从短到长。 教程 1 只有 20 行；教程 2 引入 references；教程 3 引入 scripts 与验证循环；教程 4 引入评估。每次只增加一种结构。
  5. 案例覆盖不同领域。 文档处理、代码评审、数据分析，展示同一套方法在不同风险结构下的调整。
  6. 毕业项目。 真实任务、完整交付、评分表与反模式清单，强调证据而非印象。

来源与诚实性

课程以 agentskills.io 的九个页面为主要依据，检索日期 2026-11-25。完整 URL、每页覆盖内容、外部补充资料与“哪些不是来源”都列在来源页。我们不做以下事情：

  • 不虚构规范字段、章节名、限制值或引文。
  • 不把客户端实现行为写成规范要求。
  • 不把课程的类比、时间估计、评分权重说成官方内容。
  • 不在来源不可达时凭记忆补写。

技术实现

  • 纯静态：HTML5 + 一个共享 CSS + 一个共享 JS；无框架、无构建步骤、无 npm 依赖。
  • 离线可用：不加载任何外部字体、脚本、样式或图片；系统字体栈；所有资源在本地。
  • 项目子路径：所有页面与资源引用均为相对路径，可直接部署到 https://用户.github.io/仓库名/。
  • 搜索：预生成的 assets/search-index.js 加客户端过滤，不使用 fetch，因此 file:// 下也可用。
  • 可访问性基础：lang="zh-CN"、每页一个 h1、跳转链接、可见焦点、语义化导航；未做完整的 WCAG 审计。
  • 打印：@media print 隐藏导航与搜索；检查清单按 A4 排版。

已知限制

  • 客户端差异。 教程以 VS Code + GitHub Copilot 为主，其他客户端的目录、调用语法与日志形态可能不同。格式相同，行为不完全相同。
  • 模型差异。 工具使用可靠性因模型而异；来源本身也提示了这一点。课程中的触发通过率是方法示例，不是普遍结论。
  • 来源可能更新。 规范与最佳实践会演进；课程以检索日内容为准，不保证与未来版本一致。
  • 客户端名单不完整。 展示页为动态渲染，课程未列出具体客户端，也不声称覆盖全部生态。
  • 示例可运行性。 csv-profile 附带完整脚本并已验证；三个案例的 SKILL.md 展示设计与流程，其中引用的业务脚本未随站点提供，不能直接运行。教程中的 roll-dice、release-notes、changelog-writer 可直接创建使用。
  • 评估规模。 教程 4 使用 6 条查询与 3 个用例，是为了在 50 分钟内走完流程；真实项目应按来源建议准备约 20 条查询并做多轮评估。
  • 搜索能力。 仅做标题、模块、关键词的子串匹配，不理解同义词；复杂查找请用全站索引。
  • 已部署。 本站以 GitHub Pages 项目站点形式发布：在线站点，源码见仓库。更新方式与本地预览见仓库 README。
  • 翻译。 英文术语保留原文并用括号标注；个别术语的中文译法可能与其他资料不同，以术语表为准。

使用与许可

课程文本与示例代码可自由用于学习、教学与内部培训；转载或再发布时请注明本课程名称与来源页链接。来源页面与第三方资料的版权归其各自作者所有；引用处以链接标注，未大段复制。

示例技能中的组织名、版本号、字段名与数据均为虚构或通用示例，不对应任何真实组织。请勿把案例中的业务规则直接用于生产，除非你已用自己的真实流程验证。

如何继续

  1. 按学习路径完成五个阶段。
  2. 用检查清单做提交前自检。
  3. 用毕业项目评分表评审自己与他人的技能。
  4. 回到来源页核对任何你存疑的说法。
