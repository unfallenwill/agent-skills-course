# profile.js 输出说明

## JSON 字段

- `ok`：布尔值；成功为 true。
- `rows` / `columns`：数据行数与列数。
- `headers`：列名数组，已去除 BOM 与首尾空格。
- `missing`：每列的缺失计数；空字符串、NULL、null、NA 计为缺失。
- `numeric`：仅包含全部非空值均可解析为数字的列，给出 min、max、mean。

## 退出码

- 0：成功。
- 2：参数错误（缺少 FILE、未知选项、--format 非法）。
- 3：文件不存在或不可读。
- 4：CSV 畸形（未闭合引号、重复表头、行列数不一致、空文件）。

## 汇报口径

先报行数/列数与缺失，再报数值列摘要；不要在没有说明的情况下把缺失值填 0。
