# 骰子记号规则

## 基本形式

- `dN`：掷一个 N 面骰，结果 1..N。
- `XdN`：掷 X 个 N 面骰并求和，例如 `3d6`。
- `XdNkhK`：掷 X 个，保留最高的 K 个，例如 `4d6kh3`。
- `XdNklK`：掷 X 个，保留最低的 K 个。
- `+M` / `-M`：在总和上加/减固定值，例如 `2d6+3`。

## 执行方式

逐个骰子生成结果并保留明细，再按规则求和。不要只返回总和；用户需要核对每个骰子是否在范围内。

## 边界

- X、N、K 必须是正整数；N 小于 2 或 X 大于 100 时先向用户确认。
- 记号无法解析时停止，不要猜测。
