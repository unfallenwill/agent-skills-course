# 严重级别判定指南

## Blocker

必须同时满足：能指出具体位置；能说出可复现的触发条件；后果是安全漏洞、数据丢失、越权或生产故障。缺一项就不能定为 Blocker。

## Major

在常见条件下会产生错误行为，但影响范围有限，或有明确的手动绕过方式。示例：测试代码中的真实密钥、缺少幂等导致重试重复扣款但金额可追回。

## Minor

可维护性、边界防御、错误信息不清晰；不阻塞合并。

## Nit

风格偏好；最多 3 条，并标注“可选”。不要因为个人偏好阻塞合并。

## 常见误判

- “可能有问题”但没有触发条件：降为 Major 或放入“待确认”。
- 纯格式/类型问题：交给 linter/typecheck，不报。
- 生成文件、锁文件：默认跳过，并在“未覆盖”说明。
